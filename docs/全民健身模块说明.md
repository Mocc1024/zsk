# 全民健身模块（后台）说明

> 本模块为健身房管理者设计，新增独立数据表，不改动任何原有表（含 `zsk_user`，仅写入数据、不改结构）。
> 实现日期：2026-11-24

## 一、安装步骤（按顺序执行）

本机需先启动 MySQL 服务（当前环境 3306 端口未监听，脚本无法连接）。启动后在项目根目录执行：

```bash
php scripts/run_sql.php database/upgrade_fitness_v1.sql      # 1. 建 7 张业务表
php scripts/run_sql.php database/upgrade_fitness_menu.sql    # 2. 建一级栏目「全民健身」及权限点
php scripts/gen_docs.php                                       # 3. 重新生成数据库字典/权限清单/接口文档
cd web && npm run build                                        # 4. 构建前端（代码已通过本地构建验证）
```

两个 SQL 均为幂等脚本，可重复执行。菜单 ID 段 600–699；超级管理员组（`rules='*'`）自动拥有全部权限；其他用户组需在「系统管理 → 用户组管理」中勾选具体权限点（**不要勾选菜单 ID**，否则会递归放开整个栏目）。

## 二、栏目结构

一级栏目「全民健身」（sort=95，位于内容管理之上）：

| 二级栏目 | 前端路由 | 核心内容 |
| --- | --- | --- |
| 统计管理 | `/fitness/stat` | 各门店总/今年/本月/今日业绩、已上课时、待上课时、会员数、教练数、企业数 |
| 门店管理 | `/fitness/store` | 切换门店查看上述指标；门店新增/编辑/删除 |
| 教练管理 | `/fitness/coach` | 教练列表/搜索、编辑、绑定门店/学员、绩效管理、离职 |
| 会员管理 | `/fitness/member` | 会员列表/搜索、编辑、消课、会员卡管理、删除 |
| 企业管理 | `/fitness/enterprise` | 企业列表/搜索、编辑、绑定学员、删除 |

## 三、数据表

| 表名 | 说明 |
| --- | --- |
| `zsk_fitness_store` | 门店 |
| `zsk_fitness_coach` | 教练（含 `user_id` 关联 `zsk_user`，`status` 1在职/2离职） |
| `zsk_fitness_member` | 会员/学员（含 `user_id` 关联 `zsk_user`，`lesson_balance` 课时余额按次计） |
| `zsk_fitness_enterprise` | 企业（含 `store_id`，新增必填） |
| `zsk_fitness_member_card` | 会员卡记录（业绩流水，只读） |
| `zsk_fitness_performance` | 绩效记录（业绩流水 + 加课时，单选学员，只读） |
| `zsk_fitness_lesson_consume` | 消课记录（减课时，可撤销并回滚） |

## 四、关键业务规则

1. **身份**：会员 = 学员；新增会员/加入教练时新建 `zsk_user` 账号，用户名=手机号、初始密码=手机号后 6 位；一个 `zsk_user` 只对应一个会员或一个教练；档案手机号可改但不回写 `zsk_user`，不影响前台登录。
2. **绑定基数**：1 学员只绑 1 教练 / 1 门店 / 1 企业；1 教练/企业/门店可对应多学员。
3. **业绩**：= 会员卡金额之和 + 绩效金额之和。会员卡金额归「办理时学员绑定门店」，绩效金额归「记录时教练绑定门店」，均按各自记录的日期时间（精确到秒）切分今日/本月/今年/总。历史归属不随后续改绑而变化。
4. **课时（按次数计）**：
   - 增加：教练绩效管理录入一条绩效，给所选学员增加 N 次；
   - 减少：会员管理「消课」，日期时间+次数，超出余额拒绝；消课记录可撤销并返还课时；
   - 待上课时 = 门店下所有学员课时余额合计；已上课时 = 门店消课记录次数合计。
5. **流水只读与冲销**：会员卡/绩效记录不可编辑删除；录错通过新增「负数冲销」记录纠正（金额与课时同步取负、业绩日期沿用原记录）。冲销绩效时若学员课时余额不足则拒绝。
6. **离职**：教练名下有课时余额 > 0 的学员时不允许离职；离职后解除学员绑定并禁用其 `zsk_user` 账号。
7. **删除约束**：门店下有会员/教练/企业时不可删；企业下有绑定学员时不可删；删除会员同步禁用其 `zsk_user`。
